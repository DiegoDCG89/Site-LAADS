painel.iniciar()

Gerencie eventos e patrocinadores

Publique um evento com imagem, texto e tipo, e ele aparece automaticamente na seção Próximos eventos do site. O mesmo vale para os patrocinadores da seção Parcerias.

⚠ Este painel salva os dados no armazenamento local (localStorage) deste navegador — sem um servidor por trás, é o jeito de manter tudo em um site estático. Isso significa que as alterações aparecem para quem abrir o site neste mesmo navegador/computador, mas não se sincronizam automaticamente para outros visitantes. Para um painel multiusuário de verdade (várias pessoas publicando de lugares diferentes), seria necessário um backend com banco de dados.

Eventos

PNG, JPG, JPEG, WEBP ou SVG · até 2 MB (imagens maiores são compactadas automaticamente).

Squads

Os squads cadastrados aqui aparecem automaticamente como opções no campo squad do formulário de inscrição em "Faça parte da LaADS".

Patrocinadores

PNG, JPG, JPEG, WEBP ou SVG · até 2 MB (imagens maiores são compactadas automaticamente).

Inscrições

Toda inscrição enviada pelo formulário "Faça parte da LaADS" aparece aqui. Use "Exportar CSV" para baixar um arquivo (planilha) alimentado por todas as inscrições recebidas neste navegador.

Mensagens de contato

Backup

Exporte um arquivo com todos os dados do sistema (eventos, inscrições, patrocinadores, squads, usuários, mensagens e configurações) para guardar uma cópia de segurança ou migrar para outro navegador. Ao importar um backup, os dados atuais deste navegador são substituídos — faça um backup antes, se precisar manter os dados atuais.

Segurança

Defina um novo usuário e senha para acessar este painel neste navegador.
